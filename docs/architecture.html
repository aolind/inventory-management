API Endpoints

Method Endpoint Filter Params Purpose
GET /api/inventory warehouse category Stock levels by SKU
GET /api/inventory/{id} — Single item detail
GET /api/orders warehouse category status month Order list with full filter support
GET /api/orders/{id} — Single order detail
GET /api/dashboard/summary warehouse category status month KPI aggregations for dashboard cards
GET /api/demand — Demand forecasts with trend direction
GET /api/backlog — Backlog items + has_purchase_order flag
GET /api/spending/summary — Spending totals and YTD stats
GET /api/spending/monthly — Monthly revenue vs cost breakdown
GET /api/spending/categories — Spending split by category
GET /api/spending/transactions — Recent transaction ledger
GET /api/reports/quarterly — Orders, revenue, fulfillment per quarter
GET /api/reports/monthly-trends — Month-over-month trend data
